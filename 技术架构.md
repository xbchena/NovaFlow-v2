# NovaFlow 技术架构文档

## 一、项目概述

**项目名称**: NovaFlow (不想思考了 - 智能饮食推荐系统)

**核心功能**: 基于视频分析的智能三餐推荐系统

### 产品需求
- 解决"三餐吃什么"的决策难题
- 基于用户当前位置进行推荐
- 录制附近菜市场/餐馆/食堂视频
- AI分析视频后推荐餐饮选择
- 考虑价格、人数、心情等因素
- 避免一周内重复推荐

## 五、核心模块设计

### 5.1 认证模块 (Auth)
```
功能:
├── 微信登录 (微信OAuth 2.0)
├── 手机号登录 (SMS验证码)
├── JWT Token管理 (Access + Refresh)
├── 用户偏好设置
└── 第三方登录扩展

技术实现:
- JWT: io.jsonwebtoken:jjwt-api:0.12.3
- 微信SDK: WxJava 4.6.0
- 短信: 阿里云SMS SDK
```

### 5.2 视频模块 (Video)
```
功能:
├── 视频录制 (支持位置标记)
├── 视频上传 (阿里云OSS直传)
├── 视频处理状态管理
├── 视频历史记录
└── 视频预览/播放

技术实现:
- 视频录制: Expo Camera
- 视频上传: 阿里云OSS + 断点续传
- 状态同步: WebSocket推送
```

### 5.3 推荐模块 (Recommendation)
```
功能:
├── AI视频分析 (通义千问视觉理解)
├── 智能推荐算法 (价格、人数、心情)
├── 去重机制 (一周内不重复)
├── 推荐结果缓存
└── 用户反馈收集

推荐维度:
- 场景: 菜市场/餐馆/食堂
- 餐段: 早餐/午餐/晚餐
- 价格: 经济/中等/高端
- 人数: 单人/双人/家庭(2-3人)
- 心情: 开心/疲惫/压力大
- 历史: 一周内已选项目
```

### 5.4 位置模块 (Location)
```
功能:
├── GPS定位
├── 附近商家查询
├── 地图展示
└── 位置收藏

技术实现:
```

## 六、数据模型设计

```sql
-- 用户表
CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    openid VARCHAR(128) UNIQUE COMMENT '微信OpenID',
    unionid VARCHAR(128) COMMENT '微信UnionID',
    phone VARCHAR(20) UNIQUE COMMENT '手机号',
    nickname VARCHAR(64) COMMENT '昵称',
    avatar_url VARCHAR(512) COMMENT '头像URL',
    preferences JSON COMMENT '饮食偏好 {"priceLevel": "economic", "spicyLevel": "medium"}',
    mood VARCHAR(32) COMMENT '当前心情',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_phone (phone),
    INDEX idx_openid (openid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- 视频表
CREATE TABLE video (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '视频ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    location_lat DECIMAL(10,7) COMMENT '纬度',
    location_lng DECIMAL(10,7) COMMENT '经度',
    location_name VARCHAR(256) COMMENT '位置名称',
    location_address VARCHAR(512) COMMENT '详细地址',
    oss_url VARCHAR(512) COMMENT 'OSS存储URL',
    cover_url VARCHAR(512) COMMENT '封面图URL',
    duration INT COMMENT '视频时长(秒)',
    file_size BIGINT COMMENT '文件大小(字节)',
    status VARCHAR(32) DEFAULT 'uploading' COMMENT '状态: uploading/processing/completed/failed',
    meal_type VARCHAR(32) COMMENT '餐段: breakfast/lunch/dinner',
    scene_type VARCHAR(32) COMMENT '场景: market/restaurant/canteen',
    ai_analysis JSON COMMENT 'AI分析结果',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    INDEX idx_user_id (user_id),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at),
    FOREIGN KEY (user_id) REFERENCES user(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='视频表';

-- 推荐记录表
CREATE TABLE recommendation (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '推荐ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    video_id BIGINT COMMENT '关联视频ID',
    meal_type VARCHAR(32) COMMENT '餐段: breakfast/lunch/dinner',
    scene_type VARCHAR(32) COMMENT '场景: market/restaurant/canteen',
    content JSON COMMENT '推荐内容 [{"name": "番茄炒蛋", "price": 15, "reason": "..."}]',
    ai_model VARCHAR(64) COMMENT 'AI模型版本',
    context JSON COMMENT '推荐上下文 {"peopleCount": 2, "priceLevel": "economic"}',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    INDEX idx_user_id (user_id),
    INDEX idx_video_id (video_id),
    INDEX idx_created_at (created_at),
    FOREIGN KEY (user_id) REFERENCES user(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='推荐记录表';

-- 用户选择记录表
CREATE TABLE user_selection (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '选择ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    recommendation_id BIGINT COMMENT '推荐ID',
    choice_type VARCHAR(32) COMMENT '选择类型: accept/reject/skip',
    choice_detail JSON COMMENT '选择详情 {"selectedItem": "番茄炒蛋"}',
    feedback_score INT COMMENT '反馈评分 1-5',
    feedback_text VARCHAR(512) COMMENT '反馈文本',
    actual_price DECIMAL(10,2) COMMENT '实际价格',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    INDEX idx_user_id (user_id),
    INDEX idx_recommendation_id (recommendation_id),
    INDEX idx_created_at (created_at),
    FOREIGN KEY (user_id) REFERENCES user(id),
    FOREIGN KEY (recommendation_id) REFERENCES recommendation(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户选择记录表';

-- 推荐历史表 (用于去重)
CREATE TABLE recommendation_history (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '历史ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    item_name VARCHAR(128) COMMENT '推荐项名称',
    item_type VARCHAR(32) COMMENT '类型: dish/restaurant',
    recommended_at DATE COMMENT '推荐日期',
    times_recommended INT DEFAULT 1 COMMENT '被推荐次数',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    UNIQUE KEY uk_user_item_date (user_id, item_name, recommended_at),
    INDEX idx_user_date (user_id, recommended_at),
    FOREIGN KEY (user_id) REFERENCES user(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='推荐历史表';
```

## 九、优化建议

### 9.1 后端优化

#### 1. 补充Service层
```java
// 当前问题：业务逻辑在Controller中
// 优化方案：引入Service层

@Service
public class RecommendationService {
    @Autowired
    private RecommendationRepository recommendationRepository;
    @Autowired
    private AIService aiService;
    @Autowired
    private RedisTemplate redisTemplate;

    public Recommendation generateRecommendation(Video video, RecommendContext context) {
        // 1. 检查缓存
        String cacheKey = buildCacheKey(video, context);
        Recommendation cached = (Recommendation) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return cached;
        }

        // 2. 调用AI生成推荐
        Recommendation recommendation = aiService.analyzeAndRecommend(video, context);

        // 3. 去重处理
        filterRecommendations(recommendation, context.getUserId());

        // 4. 保存并缓存
        recommendationRepository.save(recommendation);
        redisTemplate.opsForValue().set(cacheKey, recommendation, 1, TimeUnit.HOURS);

        return recommendation;
    }
}
```

```typescript
// components/ErrorBoundary.tsx
import React, { Component, ErrorInfo, ReactNode } from 'react';

interface Props {
  children: ReactNode;
}

interface State {
  hasError: boolean;
  error: Error | null;
}

export class ErrorBoundary extends Component<Props, State> {
  constructor(props: Props) {
    super(props);
    this.state = { hasError: false, error: null };
  }

  static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error };
  }

  componentDidCatch(errorInfo: ErrorInfo) {
    console.error('Error boundary caught:', errorInfo);
  }

  render() {
    if (this.state.hasError) {
      return <ErrorScreen error={this.state.error} />;
    }
    return this.props.children;
  }
}
```

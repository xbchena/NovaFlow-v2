**新建文件**: `src/theme/theme.ts`

**主题配置**:
- 颜色系统

- 圆角系统

  - 小/中/大三种阴影级别

## 3. 添加动画效果

### 3.1 动画组件库

**新建文件**: `src/components/animations/Animations.tsx`

**动画组件**:
```typescript
// 基础动画
- FadeIn         // 淡入动画
- SlideUp        // 上滑动画
- SlideInRight   // 右滑动画
- ScaleIn        // 缩放动画

// 列表动画
- StaggerInList  // 交错列表动画

// 特效动画
- LoadingSpinner // 加载转圈动画
- Pulse         // 脉冲动画
- Shake         // 摇晃动画

// 工具动画
- Skeleton      // 骨架屏动画
```

**动画配置**:
- fast: 200ms
- normal: 300ms
- slow: 500ms

### 3.2 推荐界面动画

**改进内容**:
- ✅ 卡片淡入效果
- ✅ 卡片从下向上滑入
- ✅ 交错延迟动画（每张卡片延迟50ms）
- ✅ 点击反馈动画
- ✅ 展开内容时的平滑过渡

**动画效果示例**:
```tsx
<Animated.View
  style={[
    styles.foodCard,
    {
      opacity: fadeAnim,      // 淡入
      transform: [{ translateY: slideUpAnim }], // 上滑
    },
  ]}
>
  {/* 卡片内容 */}
</Animated.View>
```
